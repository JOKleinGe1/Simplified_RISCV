Description d'un processeur RISCV simplifié. 
Toutes les instructions ne sont pas implémentéés.
(usage pédagogique). 
Le code binaire qui sert d'initialisation pour la 
mémoire d'instruction (imem) peut être généré avec 
un assembleur en ligne, par exemple celui-ci : 
https://riscvasm.lucasteske.dev/
Le code binaire généré peut être collé 
en remplacement des lignes 53-70 du fichier Riscv_simple.vhd.

La simulation du processeur peut aussi être effectuée 
en ligne, sur edaplayground. On trouve un exemple fonctionnel
ici : https://www.edaplayground.com/x/XbrS
